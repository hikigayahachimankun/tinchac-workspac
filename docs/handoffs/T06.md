## Cài và kiểm Tesseract / tái hiện

Máy thực: Ubuntu 26.04.1, **Tesseract 5.5.0**, list-langs có **eng, osd, vie**. Không cần cài thêm trong phiên. Máy Ubuntu/WSL thiếu OCR có thể dùng:

```bash
sudo apt-get install tesseract-ocr tesseract-ocr-vie tesseract-ocr-eng fonts-dejavu-core
tesseract --version
tesseract --list-langs
# Cần thấy vie và eng trước smoke thật.
.venv/bin/python -m scripts.ocr_smoke
```

Defaults từ Settings: `OCR_LANGUAGES=vie+eng`, `OCR_TIMEOUT_SECONDS=20`. Reference ngôn ngữ: [Tesseract S14](https://tesseract-ocr.github.io/tessdoc/Data-Files-in-different-versions.html). Pillow/pytesseract đã có trong requirements.lock.txt; không thêm dependency.

Ảnh local: `data/fixtures/ocr/vietnamese-clear.png`, `vietnamese-blurred.png`, `blank.png`; bản chép chuẩn `reference.txt`. Sinh từ fixture T04 bằng Pillow/DejaVuSans 36, không dữ liệu cá nhân. Hai biến thể rõ/mờ cùng 1 family tổng hợp dev; NFC + gộp whitespace, giữ dấu/case/punctuation. **n=2 ảnh, 1 family, 56 ký tự chuẩn/mẫu**: rõ 0 edits / CER 0; mờ 56 edits / CER 1. Confidence/lúc chạy thực tế trong `docs/evidence/T06/ocr-smoke.json`. Chỉ số trước sửa; không gọi là kết quả OCR có xác nhận hay benchmark.

```bash
# Từ repo root, một process demo, không live/provider.
.venv/bin/python -m scripts.init_db
.venv/bin/python -m uvicorn backend.app.main:app --host 127.0.0.1 --port 8000
# Terminal khác:
npm run dev --prefix frontend
```

Mở localhost:5173 → Ảnh → chọn ảnh clear → kiểm text → sửa 7 thành 5 triệu → tích đồng ý → xác nhận. Chưa xác nhận thì không có POST checks. Với blurred/blank, giữ cảnh báo rồi nhập mẫu trong frontend/src/api/fixture-texts.json; fixture chỉ nhận mẫu định danh. OCR failed/gián đoạn: nhập tay gửi CheckCreate text vì image contract yêu cầu ready. OCR ready/rỗng: gửi image kèm asset và text nhập tay. Các lựa chọn ở docs/decisions.md D12.
