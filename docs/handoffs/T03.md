```bash
.venv/bin/python - <<'PY'
import json
from pathlib import Path
from backend.app.models import CheckRecord, SourcePublic
source = SourcePublic.model_validate_json(Path('contracts/examples/SourcePublic.json').read_text())
for data in json.loads(Path('frontend/src/api/scenarios.json').read_text()).values():
    record = CheckRecord.model_validate(data)
    if record.result:
        for claim in record.result.claims:
            for evidence in claim.evidence:
                chunk = next(c for c in source.chunks if c.chunk_id == evidence.chunk_id)
                assert chunk.text[evidence.quote_span.start:evidence.quote_span.end] == evidence.quote
print('6 scenarios valid; all citation quotes match SourcePublic chunks')
PY
```

## API client bàn giao T04

`frontend/src/api/client.ts` xuất:

```ts
interface ApiClient {
  createCheck(input: CheckCreate): Promise<CheckCreated>;
  getCheck(checkId: string, token: string): Promise<CheckRecord>;
  getSource(versionId: string): Promise<SourcePublic>;
}
```

- `CheckCreate`, `CheckRecord` và `SourcePublic` lấy từ `components['schemas']` sinh trong `types.ts`; `ApiError.detail` là `ErrorDetail` nguyên enum T01.
- `createMockClient(scenario)` là implementation hiện tại; `pollCheck` poll 1,5 giây, ngừng tự động 120 giây, nút kiểm tra lại cùng phiên, không POST ngầm. Retry lỗi tạo request mới chỉ khi bấm nút. Token chỉ giữ trong ref memory ở App; T04 dùng `X-Resource-Token` khi làm GET thật, không query token.
- Vite proxy `/api` → `http://127.0.0.1:8000` đã cấu hình, mock chưa dùng proxy. T04 bổ sung client HTTP/runtime validation sau khi T01 được chốt, giữ error mapping và component interface; không thay API/enum để hợp UI.
