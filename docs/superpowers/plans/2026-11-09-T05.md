## Review Focus

- Separate connections racing for last budget: only one may reach provider.
- Retry after timeout: prior reservation remains charged; incomplete Usage never becomes zero.
- Valid JSON with invalid nested values/spans/duplicate ids: server validator rejects.
- Cache changes in model/prompt/schema/input/corpus/as_of/config must miss; no private durable data.
- Provider exceptions may contain keys/text: only allowlisted metadata escapes.
