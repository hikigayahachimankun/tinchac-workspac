> Execute sequentially in this session, per the user's explicit instruction. No commits, subagents, provider calls, gold access, or API/schema edits.

**Tech Stack:** Python 3.11, Pydantic v2, SQLite FTS5, scikit-learn, BeautifulSoup, PyMuPDF; existing locked dependencies.
